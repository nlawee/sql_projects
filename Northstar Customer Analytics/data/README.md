# Northstar Customer Analytics Dataset

Synthetic B2B SaaS dataset for PostgreSQL, SQL analytics, and Tableau.

## Tables
- customers
- products
- marketing_channels
- subscriptions
- orders
- support_tickets
- payments

## Project themes
Revenue, customer lifetime value, cohort retention, RFM segmentation, churn, failed-payment analysis, support analysis, rolling revenue, and churn-risk scoring.

All data is synthetic and reproducible from seed 42.
